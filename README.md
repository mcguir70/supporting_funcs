# Supporting Functions
## Written By Connor McGuire
A collection of supporting functions for various python operations.

Currently includes functions for:
- Physics
    - Compressible Flow
        - Isentropic Flow Relations
        - Normal Shock Relations
        - Oblique Shock Relations
        - Prandtl-Meyer Expansion Relations
    - Atmospheric Properties: Standard Atmosphere (USSA 1976 model)
    - Bartz Heat Transfer Coefficient
    - units
- Coding
    - typeHints
    
Any new addition should have a pytest function to test it. If you add a new function, please add a test for it in the tests/... folder.
